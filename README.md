> A powerful Scratch mod built for creators who want more speed, more control, and way more features.

**Doodle Scratch** is a feature-packed Scratch modification inspired by projects like TurboWarp, designed to push Scratch projects further while keeping the familiar block-based workflow.

## ✨ Features

- ⚡ **High-performance runtime** — optimized project execution and reduced lag
- 🚀 **60 FPS+ support** — smoother animations and games
- 🧩 **Custom extensions** — add functionality beyond standard Scratch
- 🛠️ **Advanced blocks** — extra blocks for power users
- 🎨 **Enhanced editor** — improved UI and workflow
- 🔧 **Project customization** — more control over how projects run
- 💾 **Local project support**
- 🌐 **Browser-based project player**
- 📦 **Custom project settings**
- 🎮 **Game-focused features**
- 🖥️ **Fullscreen mode**
- 🔊 **Improved audio controls**
- 📈 **Performance tools**
- 🧪 **Experimental features**

## 🚀 Getting Started

Clone the repository:

```bash
git clone https://github.com/YOUR_USERNAME/doodle-scratch.git
cd doodle-scratch
```

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

Build for production:

```bash
npm run build
```

## 📦 Compatibility

Doodle Scratch aims to maintain compatibility with standard Scratch `.sb3` projects whenever possible.

```text
.sb3 Project
     ↓
Doodle Scratch
     ↓
Edit • Run • Extend
```

Projects using Doodle Scratch-specific extensions may not work correctly in standard Scratch.
